# SubTutor – 자막 튜터

넷플릭스·유튜브·프라임 비디오·디즈니+(실험적)와 뉴질랜드 사이트(TVNZ+·ThreeNow·NZ On Screen·MĀORI+), TED·Vimeo, 그리고 사용자가 켠 아무 영상 사이트의 자막으로 영어를 공부하는 크롬 확장 프로그램과, 저장한 자막을 복습하는 웹사이트입니다. Language Reactor와 비슷한 흐름을 개인용으로 만든 것입니다.

> **코드를 고친 뒤에는** `chrome://extensions` 에서 SubTutor 카드의 새로고침(↻) 버튼을 누르고, 열려 있던 넷플릭스/유튜브 탭을 새로고침해야 새 코드가 적용됩니다. 압축해제된 확장 프로그램은 자동으로 갱신되지 않습니다.

- 웹사이트(저장 목록 · 코멘트 · 녹음 · 받아쓰기 퀴즈): **https://bluemuple.github.io/subtutor/**
- 확장 프로그램: 이 저장소의 `extension/` 폴더 (크롬에 "압축해제된 확장 프로그램"으로 설치)

## 지원 사이트 (v1.15)

| 사이트 | 자막을 읽는 곳 | 확인 |
|---|---|---|
| 넷플릭스 · 유튜브 · 프라임 비디오 · 디즈니+ | 사이트별 전용 방식 | 실제 사이트 (디즈니+ 는 실험적) |
| **TVNZ+** (tvnz.co.nz) | 플레이어가 받는 DASH 재생 목록(MPD)의 wvtt 자막 조각. 광고가 영상에 이어 붙어 있어(SSAI) 기간(Period)으로 **광고를 뺀 본편 시간**을 계산한다 | 실제 TVNZ+ 에서 TVNZ 자체 자막과 21/23 순간 일치 (2026-11-02, 어긋난 2번은 자막이 바뀌는 0.25초 경계) |
| **NZ On Screen** (nzonscreen.com) | Brightcove 재생 정보(JSON)의 WebVTT | 실제 페이지에서 자막 파일 구조 확인 |
| **TED** (ted.com) | 플레이어가 받는 언어별 통째 자막 파일 (영어·한국어만 고른다) | 실제 페이지에서 구조 확인 |
| **Vimeo** (vimeo.com) | `<track>` 요소의 WebVTT | 실제 페이지에서 구조 확인 |
| **ThreeNow** · **MĀORI+** | 위의 일반 방식(재생 목록·자막 파일·Brightcove·JSON 안 자막 주소·텍스트 트랙) | 로그인이 필요해 실제로는 확인 못 함 |
| **아무 사이트** | 그 사이트에서 툴바 아이콘(팝업) → "이 사이트에서 SubTutor 켜기" (크롬이 그 사이트 접근 권한을 묻는다). "이 사이트 목록에서 빼기"로 되돌린다 | 등록 방식만 E2E 로 확인 |

- 모든 사이트에서 **재생 화면에 ST 켜기/끄기 버튼**이 붙는다: TVNZ+ 는 오른쪽 묶음의 전체 화면 버튼 왼쪽(컨트롤이 숨었다 다시 생기면 다시 붙인다), video.js(Brightcove) 는 컨트롤 바의 전체 화면 버튼 왼쪽, 그 밖은 영상 플레이어 안의 전체 화면 버튼 왼쪽. 자리를 못 찾으면 **영상 왼쪽 위에 떠 있는 ST 버튼**(꺼도 남아 있어 다시 켤 수 있다).
- 사이트 자체 자막(Shaka·video.js·JW·Vimeo 등)은 숨기고, 페이지 안에 놓인 플레이어는 페이지를 패널 왼쪽까지로 줄인다.
- TVNZ+ 광고 중에는 영상 위 자막을 감추고 더빙을 멈춘다. 줄 이동·반복·저장한 대사의 웹 재생은 모두 본편 시간 기준이라 광고를 건너뛴 자리로 간다.
- 팝업의 "지원 사이트"와 웹 **설정 › 확장 프로그램이 되는 사이트**에서 각 사이트를 바로 열 수 있다.

## 연구 기반 훈련 (v1.16, 근거 논문은 각 기능의 ⓘ 에)

- **오늘의 훈련** (웹 첫 화면 맨 위 · 메뉴): 버튼 하나로 15분쯤 — 복습 때가 된 받아쓰기 → 단어장 카드 → 못 알아들은(Q) 문장 3개를 속도 사다리로 다시 듣기(다 들을 때까지 자막 감춤) → 더빙 한 구간 권유(플레이어에서 그 줄의 더빙 칸이 바로 열림). 그날 복습할 것이 없으면 Q 문장·최근 저장 문장으로 채운다. 마치면 🔥 연속 일수와 주별 그래프, D-day 옆에 남는다 (분산 연습 — McBride 2011).
- **고속 적응 프리셋**: 이해를 확인한 문장(받아쓰기 통과·"알고 있어")을 1 → 1.25 → 1.5 → 1배로 가속해 듣고 반드시 1배로 끝낸다(정상 속도가 느리게 들리게). 웹 목록의 ⏩ 버튼. 단계는 설정 › 속도 사다리 › 고속 적응에서 바꾸고 마지막은 1배 고정 (Griffiths 1990·1992).
- **Q 원인 태깅**: Q 문장을 복습할 때(퀴즈 채점 뒤·오늘의 훈련·목록) 원인을 원터치로 하나 — 속도 / 모르는 단어 / 축약·연음 / 키위 발음 / 문장이 김. 재생 중에는 묻지 않고 선택 사항. 진행 상황에 원인별 비율 + 다음 훈련 추천 (Wong 2017 · Medina 2020).
- **NZ 모음 주석 + 미니 퀴즈**: fish→fush(KIT)·pen→pin(DRESS)·bat→bet(TRAP)·ear=air(NEAR=SQUARE)·milk→miwk(/l/ 모음화) 유형의 고빈도 단어 약 130개에 점선 밑줄, 호버로 "NZ 발음: ~처럼 들림". 키위 용어 주석과 겹치면 키위가 우선. 웹 퀴즈의 **NZ 모음 미니 퀴즈**는 저장한 오디오를 듣고 들린 단어를 2지선다(pen vs pin)로 고른다 (Bauer et al. 2007 · Hay, Nolan & Drager 2006).
- **자주 놓치는 축약 패턴**: 받아쓰기에서 놓친 단어가 축약·연음 구간이면 gonna·didja·’em·wadder 같은 패턴으로 세어 top 10. 패턴을 누르면 그 패턴이 든 저장 문장 목록으로 (Wong 2017 · Field 2003).
- **더빙 명료도 피드백 (실험적)**: 더빙·웹 녹음과 나란히 크롬 음성 인식(인터넷 필요)을 돌려 원문 일치율 %, 내 말 속도 vs 원본 wpm, 0.3초 넘는 멈춤 수를 작게 표시. 인식이 안 되면 조용히 생략 (Anderson-Hsieh & Koehler 1988 · Derwing & Munro 2001).
- **자동 백업**: 오디오 저장 폴더가 지정돼 있으면 7일마다(또는 자막·단어 변경 50건마다) `<폴더>/SubTutor/백업/subtutor-backup-날짜.json` 을 쓴다(같은 날 덮어씀). 복원은 설정 › 데이터 › 가져오기. 설정에 상태 줄과 "지금 백업".

## 듣기 훈련 기능 (v1.5, 연구 근거는 각 기능의 ⓘ 에)

모든 설명과 학문적 근거는 화면에 늘어놓지 않고 제목 옆 **ⓘ** 를 누르면 보입니다. 모든 기능은 패널 ⚙ · 팝업 · 웹 설정에서 켜고 끌 수 있습니다.

- **한국어 표시 방식**: 항상 / T 키를 누르는 동안만(기본) / 같은 줄 3회 반복 뒤. 패널의 한국어는 흐리게 두고 마우스를 올리면 보입니다 (Mitterer & McQueen 2009).
- **못 알아들음 표시 Q**: 지금 보이는 자막을 별표 저장하고 "못 알아들음" 태그를 붙입니다. 에피소드별 1회차 이해율의 재료가 됩니다.
- **2회차 모드**: 표시한 줄만 한국어를 바로 보여 주고 패널에서 강조합니다 (두 번 보기).
- **빈칸 자막**: 기능어(약형) 또는 아무 단어를 ____ 로 가립니다. V 로 공개.
- **소리 나는 대로**: gonna, didja, 'em, an‿apple 처럼 실제로 들리는 모양을 자막 아래에.
- **키위·마오리·학교 용어 주석**: sweet as, kia ora, whānau, mat time, PB4L … 밑줄과 뜻.
- **어휘 프로파일 · 말 속도**: 상태줄에 wpm 과 3천 단어 밖 비율, 패널 "어휘 통계"에서 3천 밖 단어 목록(사전 학습용 복사)과 같은 작품 재출현.
- **단어 목록** (패널 아래 "단어 목록"): 이 영상 자막의 **모든 단어를 한 번씩**(사람 이름 제외) **두 칸**으로, 기본은 **어려운(드문) 단어부터** 보여 줍니다. "쉬운 단어부터", "쉬운 단어부터 (to·I 같은 아주 쉬운 단어 빼고)"로 바꿀 수 있고(영화·드라마 자막 2만 단어 빈도 순위 기준), **뜻 모두 보기**나 단어마다의 **뜻**을 누르면 기계 번역 뜻이 단어 오른쪽에 나옵니다. **☆** 를 누르면 그 단어가 쓰인 자막 문장과 함께 웹 **단어장**에 저장됩니다.
- **속도 사다리**: 웹의 ⤴ 버튼과 플레이어의 **X 반복**이 느린 배속부터 차례로 올라갑니다(기본 0.8→0.9→1→1.15배). 플레이어의 **S 는 배속을 바꾸지 않는 일정한 속도 반복**이고, 반복 중 S↔X 로 서로 바꿉니다. 정한 배속은 목록의 **대사마다 버튼**(`0.8` `0.9` `1` `1.15`)으로도 나와 원하는 배속만 골라 들을 수 있습니다. 웹 **설정 › 학습 기능 › 속도 사다리**나 **플레이어 ⚙ › 반복 속도 사다리**(배속 입력 + "+ 추가"/−)에서 **단계 수(1~6)** 와 **단계마다의 배속(0.3~2.0배)** 을 직접 정하고, **음높이 유지**를 켜면 느려도 목소리가 굵어지지 않고 빨라도 가늘어지지 않습니다(WSOLA 로 길이만 바꿈). 플레이어 쪽도 영상의 `preservesPitch` 를 켜 음높이를 지킵니다.
- **따라하기 모드 W**: 자막 한 줄이 끝나면 **그 자막이 떠 있던 시간 × 배율**만큼 쉬었다가 다음 자막으로 자동으로 이어 갑니다(넷플릭스·프라임·디즈니+·유튜브). 배율은 ×0.8 ~ ×2.0 중에 고르고(기본 ×1.0 = 자막이 떠 있던 시간만큼), 고정 1~7초로도 바꿀 수 있습니다. 쉬는 동안 따라 할 자막이 그대로 보입니다.
- **더빙 모드 R** (넷플릭스·프라임·디즈니+·유튜브): 지금 자막 줄 **바로 아래(패널 안, 팝업 아님)** 에 더빙 칸이 열리고 그 구간만 **계속 반복** 재생됩니다. 다른 줄을 누르거나 A·D 를 누르면 칸이 그 줄로 옮겨 가고, "+ 다음 줄 포함"으로 최대 8줄·30초까지 묶습니다.
  - ① `▶ 배속 연습` (**J**) 은 속도 사다리 단계대로 한 번씩(예: 0.5 → 0.5 → 0.7 → 1배), 옆의 `0.5` `0.7` `1` 은 반복 속도를 바꿉니다.
  - ② `● 녹음` (**K**, 한 번 더 누르면 취소) 옆의 `0.5` `0.7` `1` 로 **녹음 배속**을 고릅니다(웹 설정 › 더빙 녹음 배속, 처음은 1배, 고른 값은 다른 줄에서도 유지). 0.5배로 고르면 영상도 0.5배로 흐르며 녹음하고, 저장할 때 **음높이를 그대로 둔 채 원래 길이로 줄여**(WSOLA) 1배속 영상에 입 모양이 맞습니다. 구간마다 3개까지, 4번째부터 가장 오래된 것을 지웁니다(☆ 로 고른 것은 남김).
  - ③ 녹음이 끝나면 **가장 최근 녹음이 자동으로 ★ 더빙**이 되어, 그 구간은 **원래 소리 대신 내 녹음**으로 재생됩니다(나머지는 원래 소리, 새로고침해도 그대로). 다른 녹음을 쓰려면 그 녹음의 `☆` 를, 확인은 `▶ 들어보기`, 지우기는 `✕`.
  - 패널 맨 위 왼쪽의 **더빙 켬/끔**: 켜면 ★ 녹음이 있는 줄은 내 목소리, 끄면 원래 영상 소리만 나옵니다(작품 이름은 이 자리에서 빠졌고, 상태줄에 마우스를 올리면 보입니다).
  - 더빙 모드에서 줄을 넘겨도 더빙 칸이 패널 안에 보이는 동안은 목록이 움직이지 않고, **칸 아랫변이 패널 바닥에 닿을 때만 그 줄을 맨 위로** 한 번에 올립니다(구간을 반복 재생하는 동안에도 목록은 그대로).
  - 패널 ⚙ › **더빙**: "녹음 전에 원래 소리 먼저 듣기"(원어민 목소리를 듣고 바로 3·2·1 녹음), "녹음 뒤 내 녹음 바로 들어보기", "그다음 자막으로 넘어가 녹음 준비"를 켜면 한 줄씩 이어서 더빙할 수 있습니다.
  - **디즈니+ 시계** (실제 디즈니+ 진단 기록으로 확인, 2026-10-31): 플레이어가 알려 주는 위치(`playheadPositionMs`)는 약 0.265초 계단으로만 바뀌고, 재생·TIMECODE 이벤트는 오지 않으며, **탐색할 때마다 영상 요소의 `currentTime` 이 20초에서 다시 시작**합니다(키프레임 때문에 목표보다 최대 0.6초 일찍 재생을 시작하기도 함). 그래서 시계는 `currentTime` + 차이로 만들되, 차이는 **탐색할 때마다 버리고** 위치 값이 바뀌는 순간(0.04초마다 확인)의 보고 두 개가 맞을 때 다시 씁니다. 그 사이에는 탐색이 끝난 뒤 처음 온 보고로 어림하고(옮기기 전의 낡은 보고는 버림), 정밀 시계가 잡히는 순간 더빙 위치를 다시 맞춥니다. 재생 중인지는 플레이어 이벤트가 아니라 영상 요소로 판단합니다.
    - 예전 증상 ①: 재생 이벤트만 믿어 위치가 0.5초 계단으로 움직였고, 더빙이 보고 사이마다 "멈춤"으로 보여 **내 더빙 0.4초 · 원래 소리 0.1초**를 되풀이했다(v1.14.0 에서 고침).
    - 예전 증상 ②: 탐색 전의 차이를 계속 써서, 더빙 모드가 다음 줄로 넘어가면 시계가 10초 넘게 어긋나 "구간 밖"으로 보고 **0.5초마다 되감아 다음 줄 첫 0.4초만 되풀이**했다(v1.14.1 에서 고침). 지금은 시계를 새로 재는 동안 되감지 않고, 구간 앞에서의 되감기가 5초 안에 두 번이면 멈추는 안전장치도 있습니다.
    - 디즈니+ 의 탐색은 늘 멈춤(pause) 바로 뒤에 오므로, 멈춤 없이 0.75초 안쪽으로 오는 seeking 은 플레이어 안쪽 조정으로 보고 무시합니다.
    - 모의 디즈니+ 페이지: `?events=none`(재생 이벤트 없음), `?real=1`(위 실제 동작 전부).
  - 내 더빙이 끊기거나 원래 소리와 번갈아 나오면 ⚙ › **진단 정보**를 누르세요. 지금 상태(`clock k=… precise=… playerEvents=…`)와 **최근 40초 기록**(플레이어 보고, 영상 이벤트, 더빙을 켜고 끈 까닭)이 복사됩니다. 깜빡임이 감지되면 그렇게 하라는 안내도 뜹니다. 새로고침 직후에는 브라우저 자동 재생 규칙 때문에 화면을 한 번 누르거나 키를 눌러야(재생 버튼으로 충분) 내 더빙 소리가 나옵니다. 처음 녹음할 때 브라우저가 그 사이트의 마이크 사용을 묻습니다.
- **배속 버튼 · Shift+< / Shift+>**: 넷플릭스·프라임·디즈니+ 컨트롤 바의 ST 버튼 왼쪽에 `‹ 1× ›` 가 붙습니다. 오르내리는 **단계는 설정 › 속도 사다리에 넣은 배속**(+ 보통 1배)이고, 가운데를 누르면 1배속으로 돌아옵니다. 유튜브는 같은 단축키가 이미 유튜브 기능이라 그대로 둡니다.
- **웹**: 간격 반복 복습(1→3→7→14→30일, 퀴즈 "복습 예정"), 약점 단어(받아쓰기에서 놓친 단어 누적), 진행 상황(근무 시작일 D-day, 주별 저장·복습, 에피소드별 이해율·말 속도·어휘), 추천 콘텐츠, 쉐도잉 세션(듣기→속으로→글 보며→녹음→비교).

## 입트기 — 말하기 유창성 연습 (v1.18, 웹 ·아이폰 공통)

웹 상단의 빨간 **입트기**(설정 왼쪽), 앱 상단 왼쪽 로고 옆 **말풍선**으로 엽니다. NZ 학교에서 실제로 주고받는 말(짧게 답하기 — 교장·동료/학생/학부모, 키위 표현·관용구 위주)과 길게 말해야 하는 상황(일상·내 생각·수업·회의)의 **기본 프롬프트 48개**가 들어 있고, 프롬프트를 누르면 그 아래가 펼쳐집니다.

- **자유 말하기**: 시간 제한 없이 녹음 — 올라가는 시계 + 소리 파형, 일시정지/정지.
- **줄여 말하기**(4/3/2 기법, Nation 1989): 같은 대답을 점점 짧은 시간(기본 75→60→45초, 단계·시간은 설정에서)에 다시 말합니다. **포모도로식 원형 다운 타이머** — 시간이 넘으면 같은 방향으로 주황 띠가 덧칠되며 **+1, +2…** 올라가고, 끝나면 **몇 초 초과/부족**이 기록에 남습니다.
- 기록 줄마다: 날짜 · 길이 · (줄여) 목표와 초과/부족 · **말 속도(wpm)** · ▶ 재생 · **T 받아 적은 문장**(음성 인식) · 📝 메모 · **★ 별점(1~5)**. 지우기는 기록 줄을 **왼쪽으로 밀면** 나오는 빨간 삭제(웹은 마우스로 끌어도 됨 — 휴지통 아이콘 없음). 받아 적기가 빠졌으면 T 안의 **"다시 받아 적기"**(앱, 오디오가 그 폰에 있을 때)로 다시 돌립니다 — 앱은 권한을 묻고 기기 인식이 빈손이면 서버 인식으로 한 번 더, 웹은 인식이 끊길 때마다 다시 켜서 끝까지 받아 적습니다. 프롬프트마다 **💡 힌트**(쓰면 좋을 표현, 한국어 풀이)가 있고 기본은 감춰 둡니다(먼저 스스로 말해 보기).
- **범주 접기**: "짧게 답하기 · 교장·동료의 말" 같은 범주 제목을 누르면 접히고(상태 저장), 🎲 가 뽑은 프롬프트의 범주는 자동으로 펼쳐집니다.
- **10초 안에 끝낸 녹음은 저장하지 않기** (기본 켬, 웹은 입트기 화면의 스위치·앱은 ⚙ 설정): 잘못 누른 짧은 녹음이 기록에 쌓이지 않습니다.
- **＋ 추가**: 여러 줄을 붙여 넣으면 **한 줄 = 한 프롬프트**(앞의 번호·글머리표는 떼고, 빈 줄·중복은 버림). **✎ 편집**으로 문장·힌트를 고치고 지웁니다. **🎲 아무거나**는 최근 사흘 안 한 프롬프트 중 하나를 열어 줍니다. 맨 위에 오늘·이번 주 말한 횟수·시간.
- **동기화**: 오디오 파일은 용량 때문에 올리지 않고 **폰·웹 각자에만** 둡니다(웹은 브라우저 IndexedDB, 앱은 폰). 프롬프트와 기록(길이·날짜·별점·메모·받아 적기)만 Supabase 로 오가며, 양쪽에서 고치면 **나중에 고친 쪽**이 남습니다. 기존 Supabase 프로젝트에는 `supabase/schema.sql` 아래의 "입트기" 블록만 다시 실행하면 표 두 개가 생깁니다.

## 할 수 있는 것

**재생 화면에서 (확장 프로그램)**
- 오른쪽에 그 영상의 **전체 자막 목록** 패널. 줄을 누르면 그 위치로 이동, 지금 나오는 줄이 따라다니며 강조됩니다.
- 플레이어 컨트롤 바의 **ST 버튼**(넷플릭스: 자막 버튼 왼쪽, 유튜브: CC 버튼 왼쪽)으로 그 사이트에서 SubTutor를 켜고 끕니다. 팝업의 "이 사이트에서 SubTutor 사용" 스위치도 같습니다. 넷플릭스·프라임·디즈니+ 는 그 **왼쪽에 배속 버튼** `‹ 1× ›` 이 함께 붙습니다(SubTutor 를 끄면 같이 사라집니다).
- **유튜브**: 영상의 자막 트랙(수동 자막을 자동 생성보다 우선)을 쓰고, 한국어 자막이 없으면 유튜브 자동 번역(tlang=ko)을 같은 타이밍으로 붙입니다. 패널은 오른쪽 추천 영상 칸 위에 그 칸을 통째로 덮어 열립니다.
- 영상 위에 **영어 자막 + 같은 타이밍의 한국어 번역**을 함께 표시합니다. 넷플릭스가 제공하는 한국어 자막 트랙을 먼저 쓰고, 없으면 기계 번역으로 채웁니다. (넷플릭스 자막 설정이 영어든 꺼져 있든 상관없이 동작합니다)
- 별표 ☆ 를 누르거나 **E** 키를 누르면 그 자막을 저장합니다. 저장한 자막은 웹사이트에서 복습합니다.
- 단축키 (한/영 키보드 상태와 무관하게 물리 키 기준)

  | 키 | 동작 |
  |---|---|
  | **A** | 이전 자막 재생 |
  | **S** | 일정한 속도 반복 — 지금 자막을 지금 배속 그대로 반복 (다시 누르면 해제) |
  | **X** | 반복 속도 사다리 — 지금 자막을 반복하며 설정한 배속 단계대로 올림(예: 0.8→0.9→1→1.15, 마지막 단계로 계속). 반복 중 S↔X 로 모드 전환 |
  | **D** | 다음 자막 |
  | **F** | 지금 자막 처음부터 다시 듣기 |
  | **E** | 지금 자막 저장(별표) |
  | **P** | AP(자동 일시정지) 켜기/끄기 |
  | **W** | 따라하기 모드 켜기/끄기 |
  | **R** | 더빙 모드 켜기/끄기 (지금 자막 아래에 더빙 칸, 그 구간 반복) |
  | **J** / **K** | 더빙 칸이 열려 있을 때만: 배속 연습 / 녹음 (한 번 더 누르면 멈춤·취소). 그 밖에서는 플레이어에 넘깁니다(유튜브 J·K 그대로) |
  | **Shift+<** / **Shift+>** | 설정한 배속으로 한 단계씩 느리게/빠르게 (넷플릭스·프라임·디즈니+) |
  | **[** / **]** | 재생 속도 0.1씩 느리게/빠르게 (0.5~2×, 반복 재생에도 유지, 음높이는 그대로) |
  | **\\** | 재생 속도 1× |
  | **`** | 자막 패널 열기/닫기 |

- **AP (자동 일시정지)**: 자막이 끝나는 순간 멈춥니다. **F**를 누르면 그 부분을 다시 재생하고 다시 멈춥니다. 스페이스바나 **D**로 계속 진행합니다.
- **따라하기(쉐도잉) W**: 자막 한 줄이 끝나면 멈춰 따라 말할 틈을 주고, 그 시간이 지나면 **다음 자막으로 자동으로 이어** 갑니다. 쉬는 시간은 기본이 **그 자막이 떠 있던 시간 × 배율**입니다(×1.0 = 들은 만큼, ×1.2 = 조금 더 여유). 긴 대사는 길게, 짧은 대사는 짧게 쉬므로 줄마다 맞출 필요가 없습니다. ×1 이면 자막이 떠 있던 시간과 똑같이 쉬고(느린 배속이면 그만큼 길게), 쉬는 동안 따라 할 자막이 화면과 패널에 그대로 남습니다(다음 자막으로 넘어가지 않음). 고정 1~7초로도 바꿀 수 있습니다. 패널 헤더의 선택, 팝업에서 바꾸며, 쉬는 동안 방금 끝난 자막이 계속 표시되고 카운트다운 바가 나옵니다.
- **자막 시간 보정(영상별)**: 프라임 비디오처럼 자막 파일 시간이 영상 시간과 어긋나는 플랫폼에서는, 플레이어가 그리는 자막 문장과 대조해 보정값을 **자동으로 찾아** 영상별로 저장합니다(상태줄에 "보정 −6.2초"처럼 표시). 새 영상은 같은 플랫폼에서 마지막으로 쓴 값을 먼저 적용해 두고("−6.2초?") 자막 두 줄이 맞으면 확정합니다. ⚙ 에서 ±0.5초 버튼이나 직접 입력으로 고칠 수 있고, 저장하는 자막의 시간에도 반영됩니다.
- 재생 화면을 벗어나면(메인 페이지로 돌아가거나 프라임 플레이어를 닫으면) 패널과 자막이 자동으로 사라지고, 다시 재생하면 돌아옵니다.
- 패널이 열리면 넷플릭스·프라임·디즈니+는 **영상이 패널 왼쪽까지로 줄어들어** 가려지지 않습니다(플랫폼 CSS 규칙 + 안 먹으면 영상의 조상 요소를 찾아 너비를 줄이는 보조 방식). 유튜브는 페이지를 밀지 않고 **오른쪽 추천 영상 영역 위에 패널이 겹칩니다**(검색창은 가리지 않음).
- 디즈니+는 자막·컨트롤을 `disney-web-player` 요소의 shadow DOM 안에 그리므로, 원래 자막 숨기기 스타일을 각 shadow root 에도 넣고 요소 찾기도 shadow DOM 안까지 봅니다.
- **별표 저장 시 오디오**(⚙ 또는 팝업에서 선택): 그 대사를 한 번 다시 재생하며 오디오를 잘라 **PC에 MP3 파일로 저장**(지정 폴더/SubTutor/작품/시간 문장.mp3, 모노 128kbps)하거나 **웹 재생용으로 보관**(확장 프로그램 안, 32kHz 64kbps MP3)할 수 있습니다. **MP3 는 어느 쪽이든 하나만 만듭니다**: 파일로 저장하면 웹에서 ▶ 를 누를 때 그 파일을 읽어 재생하고(복사본 없음), 보관을 고르면 확장 프로그램 안의 MP3 로 재생합니다. 폴더를 고르지 않아 크롬 다운로드 폴더로 저장되는 경우에만, 확장 프로그램이 그 폴더를 읽을 수 없으므로 웹 재생용 복사본을 함께 둡니다. 어느 쪽이든 웹에서는 플레이어 탭 없이 바로 재생됩니다. **저장 폴더**는 팝업의 "저장 폴더 → 변경…"(설정 페이지)에서 아무 폴더나 고를 수 있고, 그 폴더 안에 SubTutor/작품/… 구조로 저장됩니다. 크롬은 확장 프로그램의 폴더 권한을 브라우저 재시작 때 다시 묻는데, 팝업의 "폴더 권한 허용"을 누르거나 설정 페이지의 "다시 묻지 않게 고정"(크롬 창에서 **매번 허용**)으로 해결합니다. 권한이 없는 동안은 다운로드 폴더에 저장됩니다. 유튜브는 영상 스트림에서 바로 캡처하고, 넷플릭스·프라임·디즈니+는 탭 오디오 캡처를 쓰므로 크롬 규칙상 **그 탭에서 확장 프로그램을 한 번 호출**해야 합니다: **Alt+E**(저장 단축키, `chrome://extensions/shortcuts` 에서 변경), 영상 **우클릭 → "SubTutor: 지금 자막 저장"**, 또는 툴바 아이콘 중 하나면 됩니다(탭마다 한 번). 허용되지 않은 상태로 별표를 누르면 안내가 뜨고, 허용되는 순간 기다리던 녹음이 바로 시작됩니다. 저장·녹음 알림은 화면을 가리지 않도록 **영상 오른쪽 위 작은 아이콘**(★ 저장, ● 녹음 중, ♪ 저장됨, 마우스를 올리면 설명)으로만 표시됩니다. 보호된 재생으로 무음이 나오면 알려 줍니다.
- **영상 오디오 통째 MP3** (패널 맨 아래 "⏺ MP3"): 지금 보는 영상의 오디오를 **보는 동안 실시간으로** 모노 64kbps MP3(1시간 ≈ 28MB)에 눌러 담아, 버튼을 다시 누르면(또는 영상이 끝나면, 에피소드가 바뀌면) `지정 폴더/SubTutor/영상 오디오/제목 날짜.mp3` 로 저장합니다(폴더가 없으면 다운로드 폴더). **일시정지한 시간과 3초 넘는 공백은 파일에 넣지 않고 이어 붙입니다.** 유튜브·TVNZ+ 같은 **DRM 없는 사이트는 영상 요소에서 바로 담아 허용 단계가 아예 없고**, 넷플릭스·프라임·디즈니+(보호된 재생)만 크롬 규칙상 탭마다 한 번 허용이 필요합니다 — **Alt+R**(Mac은 Option+R) 한 번이면 허용과 통째 녹음 시작이 동시에 됩니다(다시 누르면 저장 · Alt+E·우클릭 메뉴·툴바 아이콘도 허용이 됨, 단축키는 `chrome://extensions/shortcuts` 에서 바꿈) — 별표 저장의 대사 오디오도 같은 규칙(DRM 없으면 허용 없이 바로)을 따릅니다. ⚙ › **"에피소드를 재생하면 자동으로 오디오 MP3 녹음"**을 켜면 재생을 시작할 때 알아서 담기 시작하고, 에피소드가 바뀌면 저장한 뒤 새로 시작합니다. 탭 캡처 중에 탭을 닫거나 떠나면 15초 뒤 알아서 저장하고, 약 2시간(60MB)이 차면 끊어 저장합니다.
- **영상 오디오 → 아이폰**: 웹 설정 › 아이폰 동기화 › **서버 소리 관리**에서 뽑아 둔 통째 MP3 를 Supabase 로 올리면(전체/자동 올리기 때도 새것은 자동 — 저장 폴더를 지정하지 않아 다운로드 폴더로 간 녹음도 확장 프로그램이 자기 저장소에 복사본을 두어 그대로 올라갑니다), **웹·앱의 저장한 자막 목록 맨 위(작품 머리)에 에피소드 오디오 플레이어**가 생깁니다 — ▶(앱은 내려받기 진행률 뒤 재생) · **⏪⏩ 건너뛰기**(초는 설정에서) · **배속 −/＋**(0.5~2.0, 음높이 유지) · 자리 슬라이더. 같은 곳에서 서버에 올라간 **대사 소리(작품별)와 영상 오디오를 지워** 무료 1GB 를 관리합니다 — 지워도 이미 내려받은 기기엔 남고, 지운 영상 오디오는 "다시 올리기 허용"을 누르기 전엔 다시 안 올라갑니다.
- **장면 썸네일**: 자막을 저장하는 순간 그 장면을 **가로 150px JPEG(4~8KB)** 로 함께 담아, 웹·아이폰 목록의 대사 위에 보여 줍니다(목록 맨 위 🖼 버튼으로 모두 보이기/감추기). 자막을 가려 두어도 어떤 장면인지 짐작할 수 있습니다. Supabase `items` 표에 `thumb` 열이 필요합니다 — `supabase/schema.sql` 맨 아래 한 줄을 실행하면 되고, 실행 전에는 웹이 알아서 썸네일 없이 올립니다. **보호된 재생(넷플릭스·프라임·디즈니+)은 크롬이 디코더 단계에서 화면 픽셀을 내주지 않아**(크기를 줄여도 같음) 썸네일 없이 저장됩니다 — 유튜브·TVNZ+·일반 사이트는 됩니다.
- **가릴 때 단어 띄엄띄엄 보이기** (웹 설정 › 화면 · 앱 설정 › 표시): 자막·뜻을 가릴 때 **1·6·11…번째 단어만 남기고 나머지는 █** 로 바꿔, 전부 가려도 어떤 장면인지 짐작하게 합니다(5단어 이하 짧은 자막은 첫 단어만). 기본은 꺼짐.
- ⚙ 설정: 번역 출처(자동/플랫폼 한국어 자막만/기계 번역만/끄기), 플랫폼 기본 자막 숨기기, 자막 크기, 재생 앞뒤 여유, 영상별 자막 시간 보정, 오디오 저장 방식, 이 사이트에서 끄기, 진단 정보.

- **문장 단위로 저장** (⚙ › 저장, 기본 켬): 자막이 쉼표로 끝나거나 구두점 없이 끝나(문장이 다음 자막으로 이어지면) 문장이 끝나는 자막까지(최대 3개 더, 자막 사이가 3초 넘게 비면 거기까지) 한 항목으로 묶어 저장합니다 — 퀴즈·복습에서 문장 뒷부분이 잘리지 않습니다. 완결된 문장("… I use, OK?")은 뒤의 "- OK. Yeah…"를 따라오지 않습니다. 오디오는 자막 끝 뒤로 **꼬리 여유**(기본 4초, 0~10초)를 더 담고 기본 재생은 자막 구간까지만— 모자라면 웹 ⏱ 구간 조정에서 끝을 늘리거나 **"+ 문장 늘리기"**(함께 저장해 둔 다음 자막 3개의 글·구간을 한 줄씩 추가), 지나치면 **"− 줄이기"**.

- **편집 모드**: 툴바의 **✎ 편집**을 누르면 대사마다 선택 상자가 생기고(카드를 눌러도 선택, 묶음 제목의 "묶음 선택"으로 한 묶음 전체), 편집 막대의 **선택 n개 삭제**로 한꺼번에 지웁니다. 드롭다운 **작품·에피소드 전체 삭제…**로 특정 작품이나 에피소드의 대사를 모두 지울 수 있습니다. **완료**(또는 Esc)로 나옵니다. 삭제하면 보관 오디오, **PC 에 저장한 MP3 파일**(지정 폴더는 바로, 다운로드 폴더는 크롬 다운로드 기록으로 찾아서), 내 녹음도 함께 지워지며 되돌릴 수 없습니다. 각 대사의 "삭제" 버튼과 설정의 "자막 모두 삭제"도 같습니다.
- **오디오 구간 조정**: 각 대사의 "⏱ 구간 조정"을 누르면 넓은 슬라이더가 나옵니다. 손잡이를 끌거나(ms 단위) ←→(10ms)·Shift+←→(100ms)·±10/±100ms 버튼으로 시작과 끝을 맞추고, "▶ 들어보기"로 확인합니다. 보관된 오디오가 있으면 파형이 표시되고 그 클립 안에서 자르며, 없으면 플레이어가 조정된 구간을 재생합니다(원래 구간 앞뒤 2초까지). 조정은 바로 저장되고 "원래대로"로 되돌립니다.
- **자막/뜻 감추기**: 목록은 기본으로 자막과 뜻을 모두 감춥니다(듣기 연습용). 툴바의 "자막 모두 보이기/감추기", "뜻 모두 보이기/감추기"로 한꺼번에, 각 대사의 "자막"·"뜻" 버튼이나 가림막을 눌러 그 대사만 보이게 할 수 있습니다. 전체 감추기를 누르면 개별로 연 것도 함께 닫힙니다.
- **녹음**: 🎙 를 눌러 내 목소리를 녹음합니다. 자막당 **3개까지** 보관하고 4번째를 녹음하면 가장 오래된 것이 자동 삭제됩니다. 번호(1·2·3)를 누르면 그 녹음을 재생, **🔊 같이 듣기**를 누르면 넷플릭스 오디오 → 내 최근 녹음 순서로 이어서 들려줍니다.
- **단어장**: 패널의 단어 목록에서 ☆ 로 저장한 단어. **복습 시작**을 누르면 카드 앞면에 **단어와 그 단어가 쓰인 자막 문장**(단어 강조)이 나오고, Space 로 뒤집으면 **뜻**(기계 번역, 목록에서 고칠 수 있음)과 문장 번역이 나옵니다. **Z 잘 모름**은 10분 뒤 다시(이번 복습 안에서도 몇 장 뒤 다시), **C 알고 있어요**는 다음 복습을 1 → 3 → 7 → 14 → 30 → 60 → 120일 뒤로 늘립니다(망각 곡선에 맞춘 간격 반복). 메뉴의 숫자는 오늘 복습할 단어 수입니다.
- **퀴즈 (받아쓰기)**: 오디오만 듣고 영어로 받아쓴 뒤 확인하면 단어 단위로 맞춤/놓침/추가를 표시합니다. **Z 잊어버렸어**(이 세션과 다음 세션에 다시 나옴) / **C 알고 있어**(알고 있는 표현 상자로 이동). 퀴즈 안에서도 녹음·같이 듣기를 쓸 수 있습니다.
- **알고 있는 표현**: C로 옮긴 카드 모음. "다시 학습"으로 되돌릴 수 있습니다.
- **속도 사다리 ⤴**: 각 대사 옆의 ⤴ 를 누르면 정한 단계대로 이어서 들려줍니다. 단계 수와 배속, 음높이 유지는 설정에서 바꾸며, 보관된 오디오는 미리 길이만 바꿔 두고 1배속으로 재생하므로 목소리 높이가 변하지 않습니다.
- **대사마다의 배속 버튼**: 각 대사의 첫 줄(`자막 보기` `뜻 보기` 옆)에 설정한 배속이 그대로 버튼으로 나옵니다. 누르면 그 배속으로 재생하고, **🔁 반복**을 켠 채 누르면 그 배속으로 계속 반복합니다. 같은 배속을 다시 누르면 정지, 다른 배속을 누르면 바로 그 배속으로 바뀝니다.
- **설정**: 학습 기능 켜고 끄기, 속도 사다리 단계·배속·음높이 유지, JSON 내보내기/가져오기, MP3 폴더에서 불러오기, 통계, 전체 삭제.

- 기계 번역 결과 캐시: 확장 프로그램 로컬 저장소.
- 다른 컴퓨터로 옮기려면 웹사이트 설정 → 자막·단어장 내보내기/가져오기(JSON)를 사용하세요.
- **아이폰**: 웹 설정 › 아이폰 동기화(Supabase)로 올리면 아이폰 앱(SubTutor Pocket)이 내려받습니다 — 아래 "아이폰 앱" 참고.

## 아이폰 앱 — SubTutor Pocket (ios/)

저장한 대사를 **아이폰에서 인터넷 없이** 듣고 따라 말하는 작은 네이티브 앱입니다 (iOS 16+, SwiftUI).

- **동기화**: 맥의 SubTutor 웹 설정 › 아이폰 동기화에 로그인해 두면 접속할 때·15분마다 새것(대사·단어장·보관 소리)이 Supabase 로 자동으로 올라가고, 아이폰 앱은 **켤 때마다**(10분에 한 번) 목록을 자동으로 내려받습니다. 목록을 **아래로 당기면** 바로 동기화합니다(끝나면 진동과 함께 결과가 위에 잠깐 표시 — 새 대사 수, 실패하면 이유).
- **오디오 내려받기**: 목록은 글만 받아 가볍고, 소리(MP3)는 ① 목록 위 ⬇(전체) ② 작품 머리글 ⬇(작품별) ③ 대사를 누르면 그 자리에서 받아 재생 — 받은 대사는 초록 **Saved**, 그 뒤로는 저장된 파일이 재생돼 오프라인에서도 들립니다.
- **상단 바**: 왼쪽 앱 아이콘, 오른쪽 ⬇ 전체 다운로드 · 👁 자막 가림 · 뜻 가림 · **🔁 반복 토글**(누르면 켬/끔 — 켜 두면 대사를 누를 때 끝없이 반복, **길게 누르면 재생 속도 0.5~2배**) · ⚙ 설정.
- **듣기**: 대사를 눌러 재생(음높이 유지). 재생 버튼 아래 **계단 아이콘 = 속도 사다리**(설정한 단계대로, 기본 0.5 → 0.7 → 0.9 → 1배 — 설정에서 단계 추가·변경·삭제). 작품의 **연속 듣기**(한 대사 N번씩·대사 사이 쉼·끝나면 처음부터)는 화면을 꺼도 이어지고 잠금 화면·이어폰 버튼으로 조작합니다. 쉼 동안에는 소리 없는 오디오를 틀어 iOS 가 앱을 재우지 않게 합니다.
- **찾기·정리**: 아래 검색창(대사·뜻·메모·태그), 목록 위 **정렬**(작품별 최근/오래된 · 전체 최근/오래된 · 작품 이름순), 그 오른쪽 **🎞 작품 고르기**(맨 위 "전체 작품", 그 아래 작품명 — 회차가 여럿이면 눌러서 "이 작품 전체"와 시즌·회차를 펼치고 다시 누르면 접힘)와 **태그 칩**(누르면 그 태그만). 대사를 **오른쪽으로 밀면 초록 "알아요"** — 맨 위 **✓ 알아요** 칩으로 옮겨져 평소 목록(전체·태그)에서는 숨고, 그 칩에서 다시 밀면 "다시 학습"(웹의 "알고 있는 표현" 상자와 같은 값이라 양쪽이 이어짐). 대사를 **왼쪽으로 밀면 태그** 달기 — 웹과 함께 쓰며, 폰에서 바꾼 태그는 바로 서버로 올라가고(오프라인이면 다음 동기화 때) 웹이 다음 동기화 때 받아 갑니다(태그·알아요는 필드마다 "마지막으로 올린 값"과 비교해 바뀐 쪽만 받아 오고, 같은 대사의 같은 항목을 양쪽에서 바꾸면 나중에 바꾼 쪽). 재생·사다리·메모·녹음·같이 듣기·반복(길게 누르기 포함)·알아요에는 손끝 진동이 있습니다. 메모가 있는 대사는 📝 아이콘을 누르면 그 대사는 그대로 둔 채 아래로 펼쳐지며 다음 대사들을 밀어 내리고, 다시 누르면 위로 접힙니다.
- **말하기**: 대사마다 🎙 녹음(3개까지, 폰에만 저장), 번호를 눌러 재생, **같이 듣기**는 원음 → 내 녹음. 녹음을 마치면 **발음 확인** — iOS 음성 인식(가능하면 기기 안에서)이 내 발음을 받아 적어 원문과 비교해 **일치 %**를 붙이고, 누르면 들린 문장과 놓친 단어가 보입니다. 연속 듣기의 **따라 말할 시간**(대사 길이 ×1/×1.5/×2)을 켜면 대사마다 그만큼 쉬어 걸으면서 쉐도잉할 수 있습니다("🗣 따라 말해 보세요"). 한→영 말하기는 👁 로 영어를 가리고 뜻만 보며 말한 뒤 길게 눌러 확인(다시 길게 누르면 도로 가려짐).
- 자막·뜻 가리기: 가린 대사를 **길게 누르면 보이고, 다시 길게 누르면 도로 가려집니다**(누를 때 진동). 👁·뜻 버튼으로 가리기를 다시 켜면 열어 둔 대사도 모두 다시 가려집니다(웹과 같음).
- **입트기**: 상단 왼쪽 로고 옆 말풍선 — 위의 "입트기" 문단과 같은 기능(기본 프롬프트·자유/줄여 말하기·별점·메모·받아 적기·말 속도). 줄여 말하기 단계는 ⚙ 설정에서, 녹음 파일은 폰에만, 기록만 웹과 동기화.

**처음 설정 (Supabase, 무료)**
1. supabase.com 에서 무료 프로젝트를 만듭니다.
2. SQL Editor 에 `supabase/schema.sql` 전체를 붙여 넣어 실행합니다.
3. Authentication › Sign In / Up 에서 "Confirm email" 을 끄고, 혼자 쓸 거라면 가입 후 "Allow new users to sign up" 도 꺼 둡니다.
4. 프로젝트 URL 과 publishable 키(`sb_publishable_…`, 예전 프로젝트는 anon public 키)를 `docs/app.js` 의 `SUPA_DEFAULT_URL/KEY` 와 `ios/SubTutorPocket/Supa.swift` 의 `SupaDefaults` 에 넣으면(이 저장소에는 이미 들어가 있음), 웹·앱 모두 **이메일·비밀번호만** 입력하면 됩니다(안 넣으면 설정에 URL·키 입력칸이 보입니다). anon 키는 공개용 키이고 데이터는 RLS 로 본인 것만 열립니다.

**아이폰에 설치 (맥 필요)**
```bash
brew install xcodegen
cd ios && xcodegen            # SubTutorPocket.xcodeproj 생성
open SubTutorPocket.xcodeproj
```
Xcode 에서 Signing & Capabilities 에 본인 Apple ID 팀을 고르고, 아이폰을 꽂아 Run 하면 설치됩니다. 무료 Apple ID 서명은 7일마다 다시 Run 해야 합니다(유료 개발자 계정이면 1년). 시뮬레이터로도 그대로 돌아갑니다.

```
  options/                   설정 페이지: 저장 폴더 선택, 권한 허용, "다시 묻지 않게 고정"(매번 허용) 안내
  vendor/lamejs/             LAME MP3 인코더의 자바스크립트 포팅 (LGPL, 오디오 저장에만 사용)
  src/lib/subtitles.js       WebVTT/SRT/TTML(DFXP·IMSC) 파서, HLS 세그먼트 병합, DASH(MPD) 기간·광고 표와 MP4 자막(wvtt·stpp), 영↔한 타이밍 병합, 받아쓰기 비교
  src/background.js          저장 데이터 관리, 기계 번역(캐시), 플레이어 탭 찾기/열기, 웹 ↔ 플레이어 원격 재생 중계
  src/content/bridge.js      웹사이트와 확장 프로그램을 잇는 브리지
docs/                        GitHub Pages 웹사이트 (정적, 빌드 없음)
tests/                       파서 단위 테스트, 모의 넷플릭스 + 실제 확장 프로그램 E2E
```

- 넷플릭스는 `video.currentTime`을 직접 바꾸면 오류(M7375)로 멈추므로 플레이어 API(`seek/play/pause`)만 사용합니다.
- 넷플릭스의 최신 manifest(v4, `textTracks`/`downloadables`)와 옛 형식(`timedtexttracks`/`ttDownloadables`)을 모두 읽습니다. manifest를 못 잡으면 플레이어 상태에서 현재 자막 URL을 찾고, 다른 언어는 트랙을 잠시 바꿔 받아온 뒤 되돌립니다.
- 프라임 비디오는 실제 재생 화면에서 확인했습니다: 자막 파일 시간이 영상보다 약 6초 앞서 있어 자동 보정이 필요하고, 정지 상태에서 탐색한 직후의 `play()`가 플레이어에 의해 취소되므로 "재생 먼저 → 탐색" 순서와 재시도로 처리합니다. 디즈니+는 아직 검증하지 못한 **실험적** 상태입니다. 문제가 있으면 ⚙ → "진단 정보"를 복사해 주세요.
- 오버레이(영상 위 자막)는 플레이어 DOM 안에 넣지 않고 화면에 고정한 채 `<video>` 사각형을 따라갑니다. 플랫폼 CSS가 간섭해 엉뚱한 위치에 그려지는 일을 막기 위해서입니다.
- 기계 번역은 Google 번역의 비공식 엔드포인트를 쓰며 결과를 캐시합니다. 요청이 제한되면 1분 뒤 자동으로 다시 시도합니다.

## 알려진 한계

- 웹사이트에서 오디오를 들으려면 확장 프로그램이 설치된 크롬이어야 하고, 넷플릭스 탭이 재생 가능한 상태(프로필 선택 완료)여야 합니다. 처음 자동으로 연 탭이 소리 없이 멈춰 있으면 그 탭을 한 번 클릭해 주세요.
- 저장 데이터는 이 컴퓨터의 크롬 안에 있습니다(클라우드 동기화 없음).
- 디즈니+ 지원은 실험적입니다.
- 넷플릭스·프라임·디즈니+의 오디오 저장(탭 캡처)은 크롬 정책상 그 탭에서 확장 프로그램을 한 번 "호출"해야 허용됩니다(툴바 아이콘 클릭 = 팝업 열기). 허용 전에 별표를 누르면 안내가 뜨고, 아이콘을 누르는 순간 기다리던 녹음이 자동으로 시작됩니다. 유튜브는 필요 없습니다. 녹음은 탭 바깥의 offscreen 문서에서 합니다: 예전처럼 탭 안의 프레임에서 녹음하며 소리를 다시 틀면 그 출력이 다시 캡처되어 짧은 구간이 반복·증폭되는 되먹임이 생겼습니다(v1.4.1에서 수정). 파이프라인은 조각(10ms) 하나가 실패해도 계속 녹음하고, 녹음이 대사 길이에 크게 못 미치면 파일을 만들지 않고 이유를 알려 줍니다(보관 오디오의 `audio.stats`에 조각 수·오류·실측 샘플레이트가 남습니다).
- 오디오 저장 폴더(다운로드 폴더 밖)는 크롬의 File System Access 권한을 씁니다. 크롬은 이 권한을 브라우저 재시작 때(그리고 확장 프로그램 탭을 모두 닫으면) 거두므로, 다시 허용하기 전까지는 다운로드 폴더에 저장됩니다. 설정 페이지의 "다시 묻지 않게 고정" → 크롬 창에서 "매번 허용"을 고르면 그 뒤로는 묻지 않습니다.
