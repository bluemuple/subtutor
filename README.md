# SubTutor – 자막 튜터

넷플릭스·유튜브·프라임 비디오(디즈니+는 실험적) 자막으로 영어를 공부하는 크롬 확장 프로그램과, 저장한 자막을 복습하는 웹사이트입니다. Language Reactor와 비슷한 흐름을 개인용으로 만든 것입니다.

> **코드를 고친 뒤에는** `chrome://extensions` 에서 SubTutor 카드의 새로고침(↻) 버튼을 누르고, 열려 있던 넷플릭스/유튜브 탭을 새로고침해야 새 코드가 적용됩니다. 압축해제된 확장 프로그램은 자동으로 갱신되지 않습니다.

- 웹사이트(저장 목록 · 코멘트 · 녹음 · 받아쓰기 퀴즈): **https://bluemuple.github.io/subtutor/**
- 확장 프로그램: 이 저장소의 `extension/` 폴더 (크롬에 "압축해제된 확장 프로그램"으로 설치)

## 할 수 있는 것

**재생 화면에서 (확장 프로그램)**
- 오른쪽에 그 영상의 **전체 자막 목록** 패널. 줄을 누르면 그 위치로 이동, 지금 나오는 줄이 따라다니며 강조됩니다.
- 플레이어 컨트롤 바의 **ST 버튼**(넷플릭스: 자막 버튼 왼쪽, 유튜브: CC 버튼 왼쪽)으로 그 사이트에서 SubTutor를 켜고 끕니다. 팝업의 "이 사이트에서 SubTutor 사용" 스위치도 같습니다.
- **유튜브**: 영상의 자막 트랙(수동 자막을 자동 생성보다 우선)을 쓰고, 한국어 자막이 없으면 유튜브 자동 번역(tlang=ko)을 같은 타이밍으로 붙입니다. 패널이 열리면 페이지가 그만큼 좁아집니다.
- 영상 위에 **영어 자막 + 같은 타이밍의 한국어 번역**을 함께 표시합니다. 넷플릭스가 제공하는 한국어 자막 트랙을 먼저 쓰고, 없으면 기계 번역으로 채웁니다. (넷플릭스 자막 설정이 영어든 꺼져 있든 상관없이 동작합니다)
- 별표 ☆ 를 누르거나 **E** 키를 누르면 그 자막을 저장합니다. 저장한 자막은 웹사이트에서 복습합니다.
- 단축키 (한/영 키보드 상태와 무관하게 물리 키 기준)

  | 키 | 동작 |
  |---|---|
  | **A** | 이전 자막 재생 |
  | **S** | 지금 자막 무한 반복 (다시 누르면 해제) |
  | **D** | 다음 자막 |
  | **F** | 지금 자막 처음부터 다시 듣기 |
  | **E** | 지금 자막 저장(별표) |
  | **P** | AP(자동 일시정지) 켜기/끄기 |
  | **W** | 쉐도잉 모드 켜기/끄기 |
  | **[** / **]** | 재생 속도 0.1씩 느리게/빠르게 (0.5~2×, 반복 재생에도 유지) |
  | **\\** | 재생 속도 1× |
  | **`** | 자막 패널 열기/닫기 |

- **AP (자동 일시정지)**: 자막이 끝나는 순간 멈춥니다. **F**를 누르면 그 부분을 다시 재생하고 다시 멈춥니다. 스페이스바나 **D**로 계속 진행합니다.
- **쉐도잉**: 자막이 끝나면 설정한 시간(1~7초, 기본 2초)만큼 쉬었다가 자동으로 다음 자막으로 이어집니다. 따라 말하는 속도가 느려도 여유 있게 따라 할 수 있습니다. 쉬는 시간은 패널 헤더의 초 선택, ⚙ 설정, 팝업에서 바꿉니다. 쉬는 동안 방금 끝난 자막이 계속 표시되고 카운트다운 바가 나옵니다.
- **자막 시간 보정(영상별)**: 프라임 비디오처럼 자막 파일 시간이 영상 시간과 어긋나는 플랫폼에서는, 플레이어가 그리는 자막 문장과 대조해 보정값을 **자동으로 찾아** 영상별로 저장합니다(상태줄에 "보정 −6.2초"처럼 표시). 새 영상은 같은 플랫폼에서 마지막으로 쓴 값을 먼저 적용해 두고("−6.2초?") 자막 두 줄이 맞으면 확정합니다. ⚙ 에서 ±0.5초 버튼이나 직접 입력으로 고칠 수 있고, 저장하는 자막의 시간에도 반영됩니다.
- 재생 화면을 벗어나면(메인 페이지로 돌아가거나 프라임 플레이어를 닫으면) 패널과 자막이 자동으로 사라지고, 다시 재생하면 돌아옵니다.
- 패널이 열리면 넷플릭스·프라임·디즈니+는 **영상이 패널 왼쪽까지로 줄어들어** 가려지지 않습니다(플랫폼 CSS 규칙 + 안 먹으면 영상의 조상 요소를 찾아 너비를 줄이는 보조 방식). 유튜브는 페이지를 밀지 않고 **오른쪽 추천 영상 영역 위에 패널이 겹칩니다**(검색창은 가리지 않음).
- 디즈니+는 자막·컨트롤을 `disney-web-player` 요소의 shadow DOM 안에 그리므로, 원래 자막 숨기기 스타일을 각 shadow root 에도 넣고 요소 찾기도 shadow DOM 안까지 봅니다.
- **별표 저장 시 오디오**(⚙ 또는 팝업에서 선택): 그 대사를 한 번 다시 재생하며 오디오를 잘라 **PC에 MP3 파일로 저장**(기본은 다운로드 폴더/SubTutor/작품/시간 문장.mp3, 모노 128kbps)하거나 **웹 퀴즈용으로 보관**(확장 프로그램 안, 32kHz 64kbps MP3)할 수 있습니다. **저장 폴더**는 팝업의 "저장 폴더 → 변경…"(설정 페이지)에서 아무 폴더나 고를 수 있고, 그 폴더 안에 SubTutor/작품/… 구조로 저장됩니다. 크롬은 확장 프로그램의 폴더 권한을 브라우저 재시작 때 다시 묻는데, 팝업의 "폴더 권한 허용"을 누르거나 설정 페이지의 "다시 묻지 않게 고정"(크롬 창에서 **매번 허용**)으로 해결합니다. 권한이 없는 동안은 다운로드 폴더에 저장됩니다. 보관된 오디오가 있는 자막은 웹에서 플레이어 탭 없이 바로 재생됩니다. 유튜브는 영상 스트림에서 바로 캡처하고, 넷플릭스·프라임은 탭 오디오 캡처를 쓰므로 **그 탭에서 툴바의 SubTutor 아이콘(팝업)을 한 번 열어** 탭 허용이 필요합니다. 보호된 재생으로 무음이 나오면 알려 줍니다.
- ⚙ 설정: 번역 출처(자동/플랫폼 한국어 자막만/기계 번역만/끄기), 플랫폼 기본 자막 숨기기, 자막 크기, 재생 앞뒤 여유, 영상별 자막 시간 보정, 오디오 저장 방식, 이 사이트에서 끄기, 진단 정보.
- 플레이어 컨트롤 바의 **ST 버튼**(흰색 선 아이콘, 꺼지면 사선): 넷플릭스는 다음 회차 버튼 왼쪽, 유튜브·프라임·디즈니+는 오른쪽 버튼 묶음의 맨 왼쪽에 들어갑니다. 켜고 끄기는 포인터를 누르는 순간 반응하므로 컨트롤을 자주 다시 그리는 프라임에서도 동작합니다.
- 별표 저장 단축키: **E** 또는 **Enter**(자막이 화면에 보일 때) — 지금 화면에 보이는 자막(없으면 방금 지나간 자막)을 저장합니다.
- 유튜브 패널은 오른쪽 추천 영상 칸을 통째로 덮는 너비로 자동 조정되고(기본 400px 이상), 처음부터 검색창 아래 높이로 나타납니다. 디즈니+는 플레이어 영역(`.video_view--theater`)이 오른쪽에 붙어 있어 너비만 줄이면 영상이 오른쪽으로 밀리므로, 왼쪽에 붙이는 2단계 보정을 합니다.

**웹사이트**
- **저장한 자막**: 작품·에피소드별 목록. ▶ 를 누르면 보관된 오디오가 있으면 바로, 없으면 **플레이어 탭이 그 대사 구간만 재생**하고 멈춥니다(탭이 없으면 자동으로 엽니다). 플레이어 탭도, PC 파일도 없이 웹에서 바로 들으려면 확장 프로그램의 "별표 저장 시 오디오"를 **웹 퀴즈용으로 보관**(또는 둘 다)으로 켜 두세요. 그 뒤 별표로 저장하는 대사는 오디오가 확장 프로그램 안에 보관되어 어디서든 바로 재생됩니다. 재생 중 ◼ 를 누르면 플레이어도 바로 멈춥니다. **🔁 반복**을 켜 두면 ▶ 로 재생한 대사를 계속 반복하고, 다른 대사를 누르면 이전 것을 멈추고 그 대사를 반복합니다. 각 자막 옆에 **코멘트**를 적을 수 있고 자동 저장됩니다.
- **정렬**: 작품별 · 영상 시간순(기본) / 작품별 · 최신 저장이 위·아래 / 전체(작품 구분 없이) · 최신 저장이 위·아래 / 작품 이름순. 전체 모드에서는 각 대사에 작품 이름이 붙습니다.
- **태그**: 각 대사의 "+ 태그"로 태그를 붙입니다. 한 번 만든 태그 이름은 저장되어 다른 대사에서 고를 수 있고, 목록 맨 위의 태그를 누르면 그 태그가 붙은 대사만 보입니다(퀴즈도 태그로 범위를 좁힐 수 있음).
- 각 대사의 시간 옆에 작은 배지로 오디오 저장 형태가 표시됩니다: `♪ MP3`(확장 프로그램에 보관, 마우스를 올리면 샘플레이트·길이) · `⬇ MP3`(PC 파일, 저장 경로).
- **오디오 구간 조정**: 각 대사의 "⏱ 구간 조정"을 누르면 넓은 슬라이더가 나옵니다. 손잡이를 끌거나(ms 단위) ←→(10ms)·Shift+←→(100ms)·±10/±100ms 버튼으로 시작과 끝을 맞추고, "▶ 들어보기"로 확인합니다. 보관된 오디오가 있으면 파형이 표시되고 그 클립 안에서 자르며, 없으면 플레이어가 조정된 구간을 재생합니다(원래 구간 앞뒤 2초까지). 조정은 바로 저장되고 "원래대로"로 되돌립니다.
- **자막/뜻 감추기**: 목록은 기본으로 자막과 뜻을 모두 감춥니다(듣기 연습용). 툴바의 "자막 모두 보이기/감추기", "뜻 모두 보이기/감추기"로 한꺼번에, 각 대사의 "자막"·"뜻" 버튼이나 가림막을 눌러 그 대사만 보이게 할 수 있습니다. 전체 감추기를 누르면 개별로 연 것도 함께 닫힙니다.
- **녹음**: 🎙 를 눌러 내 목소리를 녹음합니다. 자막당 **3개까지** 보관하고 4번째를 녹음하면 가장 오래된 것이 자동 삭제됩니다. 번호(1·2·3)를 누르면 그 녹음을 재생, **🔊 같이 듣기**를 누르면 넷플릭스 오디오 → 내 최근 녹음 순서로 이어서 들려줍니다.
- **퀴즈 (받아쓰기)**: 오디오만 듣고 영어로 받아쓴 뒤 확인하면 단어 단위로 맞춤/놓침/추가를 표시합니다. **Z 잊어버렸어**(이 세션과 다음 세션에 다시 나옴) / **C 알고 있어**(알고 있는 표현 상자로 이동). 퀴즈 안에서도 녹음·같이 듣기를 쓸 수 있습니다.
- **알고 있는 표현**: C로 옮긴 카드 모음. "다시 학습"으로 되돌릴 수 있습니다.
- **설정**: JSON 내보내기/가져오기, 통계, 전체 삭제.

## 설치

1. 이 저장소를 내려받습니다 (`Code → Download ZIP` 또는 `git clone`).
2. 크롬에서 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → `extension/` 폴더를 선택합니다.
4. 넷플릭스·유튜브·프라임에서 영상을 재생하면 오른쪽에 패널이 나타납니다. (이미 열려 있던 탭은 새로고침)
5. 웹사이트 https://bluemuple.github.io/subtutor/ 를 열면 확장 프로그램이 자동으로 연결됩니다. (확장 프로그램 팝업이나 패널 ⚙ 의 "웹에서 저장 목록 · 퀴즈 열기" 버튼으로도 열립니다)

> Language Reactor를 같이 켜 두면 패널과 단축키가 서로 겹칩니다. SubTutor를 쓸 때는 Language Reactor를 잠시 꺼 두는 것을 권합니다.

## 데이터가 저장되는 곳

- 저장한 자막·코멘트·퀴즈 기록·설정: 크롬 확장 프로그램의 로컬 저장소(`chrome.storage.local`). 웹사이트는 확장 프로그램을 통해 이 데이터를 읽고 씁니다. 그래서 **웹사이트는 확장 프로그램이 설치된 크롬에서만** 내용이 보입니다.
- 녹음: 웹사이트 도메인의 브라우저 저장소(IndexedDB).
- 기계 번역 결과 캐시: 확장 프로그램 로컬 저장소.
- 다른 컴퓨터로 옮기려면 웹사이트 설정 → 내보내기/가져오기(JSON)를 사용하세요.

```
  src/content/content.js     패널·오버레이(화면 고정, video 사각형 추적)·단축키·반복·AP·쉐도잉·저장·오디오 캡처·원격 재생·시간 보정
  src/lib/audio.js           PCM 자르기, 벽시계↔영상시간 맞추기, 리샘플, MP3(lamejs)/WAV 인코딩
  offscreen/capture.html(.js) 탭 오디오 녹음용 offscreen 문서: 서비스 워커가 chrome.tabCapture.getMediaStreamId 로 받은 스트림 ID 로 getUserMedia, 대사 구간을 MP3 로 자름. 탭 바깥이라 녹음 중 소리를 들려줘도 되먹임이 없음
  src/lib/fs.js              오디오 저장 폴더 핸들(File System Access) 보관·권한 확인·파일 쓰기 (서비스 워커/팝업/설정 페이지 공용)
  options/                   설정 페이지: 저장 폴더 선택, 권한 허용, "다시 묻지 않게 고정"(매번 허용) 안내
  vendor/lamejs/             LAME MP3 인코더의 자바스크립트 포팅 (LGPL, 오디오 저장에만 사용)
  src/lib/subtitles.js       WebVTT/SRT/TTML(DFXP·IMSC) 파서, HLS 세그먼트 병합, 영↔한 타이밍 병합, 받아쓰기 비교
  src/background.js          저장 데이터 관리, 기계 번역(캐시), 플레이어 탭 찾기/열기, 웹 ↔ 플레이어 원격 재생 중계
  src/content/bridge.js      웹사이트와 확장 프로그램을 잇는 브리지
docs/                        GitHub Pages 웹사이트 (정적, 빌드 없음)
tests/                       파서 단위 테스트, 모의 넷플릭스 + 실제 확장 프로그램 E2E
```

- 넷플릭스는 `video.currentTime`을 직접 바꾸면 오류(M7375)로 멈추므로 플레이어 API(`seek/play/pause`)만 사용합니다.
- 넷플릭스의 최신 manifest(v4, `textTracks`/`downloadables`)와 옛 형식(`timedtexttracks`/`ttDownloadables`)을 모두 읽습니다. manifest를 못 잡으면 플레이어 상태에서 현재 자막 URL을 찾고, 다른 언어는 트랙을 잠시 바꿔 받아온 뒤 되돌립니다.
- 프라임 비디오는 실제 재생 화면에서 확인했습니다: 자막 파일 시간이 영상보다 약 6초 앞서 있어 자동 보정이 필요하고, 정지 상태에서 탐색한 직후의 `play()`가 플레이어에 의해 취소되므로 "재생 먼저 → 탐색" 순서와 재시도로 처리합니다. 디즈니+는 아직 검증하지 못한 **실험적** 상태입니다. 문제가 있으면 ⚙ → "진단 정보"를 복사해 주세요.
- 오버레이(영상 위 자막)는 플레이어 DOM 안에 넣지 않고 화면에 고정한 채 `<video>` 사각형을 따라갑니다. 플랫폼 CSS가 간섭해 엉뚱한 위치에 그려지는 일을 막기 위해서입니다.
- 기계 번역은 Google 번역의 비공식 엔드포인트를 쓰며 결과를 캐시합니다. 요청이 제한되면 1분 뒤 자동으로 다시 시도합니다.

## 개발 · 테스트

```bash
npm test                      # 파서·오디오 단위 테스트 (node --test, ffprobe 필요)
npm run sync-lib              # extension/src/lib/subtitles.js → docs/subtitles.js 복사 (둘은 같은 파일이어야 함)
# E2E: Chrome for Testing(puppeteer) + 실제 확장 프로그램 + 모의 넷플릭스(https://www.netflix.com → 127.0.0.1:8443) + 웹사이트(localhost:8766)
npm i -D puppeteer            # 최초 1회 (Chrome for Testing 내려받음)
openssl req -x509 -newkey rsa:2048 -nodes -keyout tests/e2e/.tmp/key.pem -out tests/e2e/.tmp/cert.pem -days 60 -subj "/CN=www.netflix.com"
npm run e2e                   # 43개 시나리오: 패널/오버레이/단축키/AP/쉐도잉/저장/켜기끄기/시간보정/유튜브/오디오 캡처·폴더 저장/웹 재생·정지·반복/감추기/코멘트/녹음/퀴즈
```

E2E는 헤드리스로 돌며 `tests/e2e/.tmp/shots/`에 스크린샷을 남깁니다. 모의 영상은 ffmpeg로 생성됩니다.

## 알려진 한계

- 웹사이트에서 오디오를 들으려면 확장 프로그램이 설치된 크롬이어야 하고, 넷플릭스 탭이 재생 가능한 상태(프로필 선택 완료)여야 합니다. 처음 자동으로 연 탭이 소리 없이 멈춰 있으면 그 탭을 한 번 클릭해 주세요.
- 저장 데이터는 이 컴퓨터의 크롬 안에 있습니다(클라우드 동기화 없음).
- 디즈니+ 지원은 실험적입니다.
- 넷플릭스·프라임·디즈니+의 오디오 저장(탭 캡처)은 크롬 정책상 그 탭에서 확장 프로그램을 한 번 "호출"해야 허용됩니다(툴바 아이콘 클릭 = 팝업 열기). 허용 전에 별표를 누르면 안내가 뜨고, 아이콘을 누르는 순간 기다리던 녹음이 자동으로 시작됩니다. 유튜브는 필요 없습니다. 녹음은 탭 바깥의 offscreen 문서에서 합니다: 예전처럼 탭 안의 프레임에서 녹음하며 소리를 다시 틀면 그 출력이 다시 캡처되어 짧은 구간이 반복·증폭되는 되먹임이 생겼습니다(v1.4.1에서 수정). 파이프라인은 조각(10ms) 하나가 실패해도 계속 녹음하고, 녹음이 대사 길이에 크게 못 미치면 파일을 만들지 않고 이유를 알려 줍니다(보관 오디오의 `audio.stats`에 조각 수·오류·실측 샘플레이트가 남습니다).
- 오디오 저장 폴더(다운로드 폴더 밖)는 크롬의 File System Access 권한을 씁니다. 크롬은 이 권한을 브라우저 재시작 때(그리고 확장 프로그램 탭을 모두 닫으면) 거두므로, 다시 허용하기 전까지는 다운로드 폴더에 저장됩니다. 설정 페이지의 "다시 묻지 않게 고정" → 크롬 창에서 "매번 허용"을 고르면 그 뒤로는 묻지 않습니다.
